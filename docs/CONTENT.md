# Як змінювати контент

Усі тексти лежать у `src/content/`. Кожен файл це звичайний обʼєкт із типом: якщо випадково видалити потрібне поле, `npm run check` покаже помилку ще до публікації.

Цей документ поповнюється разом із секціями. Для кожної нової секції тут зʼявляється рядок, де шукати її тексти.

## Файли

| Файл | Що в ньому |
|---|---|
| `src/content/site.ts` | імʼя, підпис, опис для пошуковиків, посилання на Telegram і WhatsApp |
| `src/content/home.ts` | тексти секцій головної. Блок `hero`: заголовок, текст у плашці, підпис кнопки, дві цифри, блок про досвід |

## Типові правки

**Змінити опис сайту для Google.** Файл `src/content/site.ts`, поле `description`.

**Додати посилання на месенджер.** Файл `src/content/site.ts`, блок `contacts`. Telegram у вигляді `https://t.me/імʼя`, WhatsApp у вигляді `https://wa.me/380XXXXXXXXX`. Поки поле порожнє, кнопка на сайті не показується.

## Фото

Нові фото кладіть у `public/images/`. Вихідний файл може бути великим (JPG або PNG до 3000 px по довшій стороні), Next.js сам стисне його й віддасть у сучасному форматі потрібного розміру.

## Перша секція (hero)

**Тексти й цифри.** Файл `src/content/home.ts`, блок `hero`.

**Кольори фону.** Файл `src/components/sections/hero/LiveGradient.tsx`, список `RAMP`: шість кольорів від найглибшого до найсвітлішого, і `CORNER` для затемненого правого нижнього кута.

**Характер руху фону.** Числа на початку того самого файлу: `SPEED` (швидкість течії), `SCALE` (розмір плям), `CONTRAST` (різниця між світлими й темними плямами), `CURSOR_SHIFT` (наскільки курсор перебудовує плями), `CURSOR_GLOW` (наскільки фон світлішає під курсором), `CURSOR_EASE` (інерція курсора: менше число дає плавніший рух).

**Картинка фону до старту анімації.** Її видно в першу мить, а також там, де анімація вимкнена. Це нерухомий градієнт із макета: кольори в `src/components/sections/hero/mesh.ts`, після зміни запустіть

```bash
node scripts/gradient-poster.mjs
```

**Поява блоків.** Розклад (що за чим зʼявляється, у мілісекундах) лежить у `AT` на початку `src/components/sections/hero/Hero.tsx`.

**Сила світла на фото.** Числа на початку `src/components/sections/hero/RelitPortrait.tsx`: `STRENGTH` (загальна сила), `RELIEF` (виразність рельєфу), `POOL` (пляма світла біля курсора), `WARMTH` (теплота).

### Заміна фото в hero

Ефект світла привʼязаний до конкретного знімка, тому разом із фото треба оновити карту рельєфу.

1. Підготуйте портрет: PNG із прозорим фоном, пропорції приблизно 1471×1280, людина дивиться ліворуч. Збережіть як `public/images/hero-portrait.png`.
2. Згенеруйте для нього карту глибини (depth map) у будь-якому сервісі, наприклад Depth Anything: сірий PNG того самого розміру, ближче до камери світліше. Найкраще 16-бітний. Збережіть як `design-src/hero-portrait-depth.png`.
3. Запустіть

```bash
node scripts/normal-map.mjs public/images/hero-portrait.png design-src/hero-portrait-depth.png public/images/hero-portrait-normal.png
```

4. Перевірте на сайті: проведіть курсором навколо портрета. Якщо світло лягає плямами або «навпаки», карта глибини невдала, згенеруйте іншу.

Якщо карту рельєфу не оновити, світло рухатиметься за формою старого знімка.
