# Передача проєкту

Сайт розроблено студією Fooror. Розробка йде локально, проміжні версії власник бачить за тимчасовим посиланням. Готовий сайт публікується одразу на акаунтах власника, тож переносити між акаунтами нічого не треба.

## Що входить у передачу

| Що | Де живе | Стан |
|---|---|---|
| Код | GitHub власника, репозиторій `zhukov` | ще не створено, код локально у студії |
| Хостинг | Vercel власника, проєкт `zhukov` | ще не створено |
| Домен | реєстратор власника | ще не підключено |
| Telegram-бот для заявок | BotFather на акаунті власника | ще не створено |

Цю таблицю оновлюємо на кожному кроці.

## Порядок запуску

1. **GitHub.** Власник створює акаунт і порожній приватний репозиторій `zhukov`, додає студію як учасника (Settings → Collaborators). Студія пушить туди код з усією історією.
2. **Vercel.** Власник створює акаунт, натискає Add New → Project і обирає репозиторій `zhukov`. Налаштування збірки Vercel визначає сам.
3. **Тариф Vercel.** Безкоштовний Hobby за умовами Vercel призначений для некомерційних проєктів. Сайт бізнесу має працювати на Pro.
4. **Змінні середовища.** У Vercel: Project Settings → Environment Variables. Перелік і пояснення в `.env.example`.
5. **Telegram-бот.** Власник створює бота в BotFather, токен і chat id вписує у змінні `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID`, а `LEAD_DRY_RUN` ставить `false`.
6. **Домен.** Лишається в реєстратора власника. DNS-записи, які треба додати, показує Vercel у Project Settings → Domains.
7. **Індексація.** На бойовому домені виставити `ALLOW_INDEXING=true` і `SITE_URL=https://домен`, далі Redeploy.
8. **Контрольна правка.** Власник клонує репозиторій, просить свій Claude змінити будь-який текст за `docs/CONTENT.md`, отримує превʼю і публікує. Передача вважається завершеною, коли цей крок пройшов.
9. Студія виходить із доступів або лишається учасником, якщо домовлено про супровід.

## Секрети

Токени й ключі передаються через менеджер паролів, не в листуванні. Якщо токен бота хоч раз побував у чаті чи пошті, його варто перевипустити в BotFather командою `/revoke`.
